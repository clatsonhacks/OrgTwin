## Requirements that shape the build
- Production-style web app with a **Vultr VM backend**, deployed on Vultr.
- Vultr must be the central control/orchestration layer, not just static hosting.
- Serverless Inference: required for Challenge 1, optional for Challenge 2 (we use it for everything).
- Submit on lablab.ai: title, descriptions, tags, cover image, video, slides, public GitHub repo,
  public application URL.
- README must cover the Vultr services used, the architecture, the agent use case and setup.
